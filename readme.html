mac-dev-setup.

One script that sets up a Mac for development: Homebrew, the kitty terminal with a neon theme, modern command-line tools, Claude Code, and zsh/bash config.

Quick start

git clone <repo-url> ~/mac-dev-setup
~/mac-dev-setup/install.sh

Then quit kitty fully (cmd+Q), reopen it, and open a new shell. The script is safe to run again at any time: anything already installed is skipped and files that already match are left alone.

What install.sh does

  1. Homebrew (macOS only): installs it with the official installer if missing. It asks for your password.
  2. kitty: brew install --cask kitty if it is not already in Homebrew or /Applications.
  3. CLI tools: installs any of eza bat fd fzf zoxide that are missing.
  4. Claude Code: Anthropic's native installer, into ~/.local/bin, if claude is missing. Runs on Linux too.
  5. Config files: copies them into place. An existing file that differs is backed up first as <name>.bak-<timestamp>.

Options

CommandEffect
./install.shEverything
./install.sh --no-brewSkip Homebrew, kitty and the CLI tools
./install.sh --no-claudeSkip Claude Code

./install.sh --helpShow usage

To change which CLI tools are installed, edit brew_tools=(…) near the top of install.sh.

Shell

zshrc and bashrc set up the same environment for each shell:

  • Prompt: user@host:~/path (branch*) ↑1 ❯ with git status, ahead/behind counts and any rebase or merge in progress.
  • PATH: ~/.local/bin first, then Homebrew.
  • History: 100,000 entries, shared between shells, duplicates removed. Start a command with a space to keep it out.
  • Completion: case-insensitive, with a menu.
  • Editor: nvim if installed.

Keeping the repo up to date

The installed files are copies, not links, so your setup keeps working without the repo. After changing a live file, copy it back and commit:

cp ~/.config/kitty/kitty.conf ~/.config/kitty/theme.conf ~/mac-dev-setup/
cp ~/.zshrc ~/mac-dev-setup/shell/zshrc
cp ~/.bashrc ~/mac-dev-setup/shell/bashrc
cd ~/mac-dev-setup && git commit -am "Update config"

Notes

  • background_blur needs kitty 0.32 or later.
  • The macos_* kitty options are ignored on Linux, and the Homebrew step is skipped there.
  • On macOS, bash usually starts as a login shell, which reads ~/.bash_profile rather than ~/.bashrc. zsh, the macOS default, is not affected.
  • Some settings (such as the title bar color) only apply after restarting kitty, not on reload.
